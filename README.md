# BunkMeter — Know Your Bunk Limit

A static, no-login attendance calculator built with HTML, CSS, and vanilla JavaScript.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in any modern browser.
3. Use **Use it for free** on the landing page to open the calculator in a new tab.

No build tools, backend, database, account, or dependencies are required.

## Features

- Landing page explaining how BunkMeter works
- Separate calculator view using `?page=calculator`
- Lecture mode and day mode (including lectures per day)
- Keyboard-editable required attendance percentage
- Projected attendance, bunk limit, and recovery calculation
- Creator credit linking to Vipin Prajapati's LinkedIn profile
- Responsive styling

## Deploy

### GitHub Pages
Upload `index.html` to a repository, enable GitHub Pages in repository settings, and publish from the selected branch.

### Vercel
Import the repository into Vercel as a static site. No build command is needed; set the output directory to `.` if prompted.
